# CLI Task Manager

CLI Task Manager is an open-source educational project, developed in TypeScript.
This project aims to learn TypeScript and to develop GitHub Actions (CI/CD) skills.

## Technologies used

This project uses:
    - TypeScript (Node.js)
    - GitHub Actions

## Liscence

This project uses the Apache 2.0 Liscence

## Conventional Commit (CC)

This project uses the Conventional Commit. Here is the syntax used :
feat: ADD A NEW FEATURE
fix: FIX SOME BUGS
docs: EDIT THE DOCUMENTATION (DOC ONLY)
style: FORMAT CODE
